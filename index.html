    현재는 키 없이도 바로 테스트할 수 있는 즉시 미리보기 지도가 켜져 있어요! 실제 카카오맵(Kakao Maps SDK)과 실시간 장소 검색을 쓰려면 아래에 카카오 JavaScript 키를 넣어주세요.

    1. Kakao Developers 접속 후 [내 애플리케이션] 생성
    2. [플랫폼] → [Web]에 현재 주소(예: http://localhost:5500 또는 http://127.0.0.1:5500) 등록
    3. [앱 키] 메뉴에서 JavaScript 키를 복사해 아래에 붙여넣기!
    4. (중요) 카카오 장소 키워드 검색까지 쓰려면 [제품 설정] → [카카오맵]에서 사용 설정을 ON으로 켜주세요!
